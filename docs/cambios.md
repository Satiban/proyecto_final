### Resultado de la revisión de observaciones del PSet 3

Las siete observaciones docentes se abordaron mediante la reconstrucción del pipeline de modelado y las comprobaciones adicionales:

- **EDA y features:** se incorporó una ablación que cuantificó el aporte incremental, sin atribuir mejoras no demostradas.
- **Preparación y validación:** se reservó el hold-out para los finalistas y se implementó validación temporal purgada.
- **Líneas base y candidatos:** se evaluaron cinco familias tabulares y un LLM real con Ollama.
- **Hiperparámetros:** se diferenciaron las mejoras numéricas de la variabilidad entre pliegues.
- **MLflow:** se separaron conceptualmente y mediante nombres las métricas de validación y prueba.
- **Selección y negocio:** se reconoció que contactar a todos fue más económico en validación OOF y que el champion no demostró una ventaja robusta en prueba.
- **Reproducibilidad:** se reorganizó el proyecto mediante `src/pipeline.py`, cinco notebooks numerados, resultados exportados, Model Registry y pruebas automatizadas.

Las modificaciones de interpretación y documentación no requirieron repetir los experimentos de tuning ni registrar nuevas versiones del champion. La ablación fue una evaluación adicional sobre entrenamiento que no utilizó el hold-out.

**Limitación general:** el rendimiento obtenido corresponde a un dataset sintético y no demuestra que el modelo permita reducir el abandono clínico o los costos operativos en una institución real.
